# Final figure common-support contract

Formal native mosaics use `native.mode = all_source_groups` with `sax`, `2ch`, and `4ch`. SAX is observed in every sparse condition; LAX source groups are labelled from the immutable sparse manifest. L100 has no held-out labels.

For ordinary longitudinal panels, all comparison methods use one physical plane and exactly this display support:

`frozen_L100_display_mask AND in_volume(all configured comparison methods) AND finite(all configured comparison methods)`.

For SCMR-style centre-line panels, the source overlay may show its full source context. The quantitative source reformat and Fit-first/Q002/Q004 panels use one common support:

`source comparison domain AND in_volume(all configured comparison methods) AND finite(all configured comparison methods)`.

The figure manifest records the equation and common-support pixel count. It does not autocrop comparison panels, and preserves physical aspect ratio.
