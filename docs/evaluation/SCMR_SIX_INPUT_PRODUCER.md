# Historical SCMR six-input producer

The producer reads the historical `common_mask_manifest.json` generated by
`prepare_common_evaluation_mask.py`. For every parameter-specific correspondence
record its sources are: `original_ms` (oriented native map), `registered_ms`
(the parameter's final registered NeSVoR slice), `synthetic_ms` (PSF simulated
on that same final registered geometry), `training_mask` (registered-slice
mask), `synthetic_support` (finite/non-zero PSF simulation support), and
`fitting_valid_mask` (the oriented historical native valid-mask). These are the
six historical strict-common inputs; Proposed and current Fit-first predictions
are never substituted for them.

An explicit `scmr_historical_group_mapping/v1` is mandatory. It maps historical
`native_slice_id` to current `original_group_idx`; file ordering is not identity.
The frozen current L100 support is separately supplied as
`phase4r_l100_native_support/v1`, one explicit plane per parameter/stack/group.
The existing immutable `q004_direct_native_endpoint_audit/v2` is also an
accepted frozen-native source: its explicit `planes/.../groupNNN.npz`,
`group_idx`, and `l100_native` field are copied as `phase4r_l100`. This is a
provenance adapter only; it does not recompute or interpolate the L100 mask.

For every historical input the producer proves either `IDENTICAL_GRID` or
`EXACT_REORIENTABLE_GRID`: a 2-D signed axis permutation, flips and integer
offset with one-to-one indices and matching physical coordinates. Values and
masks are copied only by those integer indices. Fractional shifts, scale,
shear, arbitrary rotation, out-of-bounds/crop ambiguity, or missing provenance
raise `SCMR_SIX_INPUT_GEOMETRY_NOT_EXACTLY_REINDEXABLE`; interpolation is never
used.

```text
historical six inputs -> exact discrete-grid proof -> current [row,col] bundle
-> strict common -> 8-connected centre/largest component -> final figures/metrics
```

`phase4r_l100_central_component` remains a control and cannot replace the
historical six-input SCMR support.

`build_scmr_six_input_bundle.sh discover` is read-only. It prints a record for
every required `(parameter, stack, original_group_idx)` identity in `FOUND` or
`MISSING`, and refuses a build unless all 82 CYJ L100 planes are present. The
group-map manifest is intentionally a required input: historical
`native_slice_id` must never be matched to current `original_group_idx` by file
order. A build writes only a new, absent output directory and records SHA256,
source/output voxel counts, discrete-grid proof, L100 field/provenance and R0
source-support provenance for every plane.

Example server invocations (substitute only completed immutable artifact
paths):

```bash
paper_experiments/joint_vs_2dfit/phase2_clean/server_commands/build_scmr_six_input_bundle.sh \
  discover COMMON_MASK_MANIFEST GROUP_MAPPING_V1 R0_NATIVE_ROOT L100_SPARSE_MANIFEST \
  Q004_FROZEN_NATIVE_AUDIT /home/dengyz/miniconda3/envs/nesvor/bin/python

paper_experiments/joint_vs_2dfit/phase2_clean/server_commands/build_scmr_six_input_bundle.sh \
  build COMMON_MASK_MANIFEST GROUP_MAPPING_V1 R0_NATIVE_ROOT L100_SPARSE_MANIFEST \
  Q004_FROZEN_NATIVE_AUDIT /home/dengyz/miniconda3/envs/nesvor/bin/python \
  NEW_SCMR_SIX_INPUT_NATIVE_BUNDLE
```

The produced root is consumed directly by
`build_scmr_central_component_masks.sh SIX_INPUT_ROOT SCMR_MASK_V2 PYTHON`.
